# 規格書：日本旅遊規劃師（Japan Trip Planner）

## 1. 想法與目標
想去日本玩的人常常「景點太多不知道怎麼排、不知道要帶多少錢」。
這個網頁讓使用者在同一頁完成：挑景點 → 排行程（含時間與自訂內容）→ 估預算 → 整理行李 → 輸出 PDF → 學幾句實用日文。

## 2. 目標使用者
- 計畫自助去日本旅遊的台灣旅客（繁體中文介面）
- 想快速得到行程與預算概念的新手

## 3. 功能需求
| 編號 | 功能 | 說明 |
|---|---|---|
| F1 | 景點探索 | 12 個日本代表景點卡片；可依類別（文化／美食／自然／購物／都會）、城市、季節、關鍵字篩選 |
| F2 | 加入行程 | 卡片按鈕可加入指定的第 N 天；重複加入會改為移到新的一天 |
| F3 | 行程規劃 | 可設定旅遊天數（2–10 天），依天顯示行程，可換天、移除 |
| F4 | 預算計算 | 景點與自訂項目花費 + 每日餐費 + 每日交通 + 住宿 + 機票，依匯率換算成台幣 |
| F5 | 隨機選景點 | 「不知道去哪」按鈕，隨機推薦一個景點 |
| F6 | 行李清單 | 預設清單，可勾選、新增、刪除，顯示完成進度 |
| F7 | 實用日文 | 常用句子，可點擊朗讀（瀏覽器語音）與複製 |
| F8 | 資料保存 | 行程、預算設定、行李清單、旅程名稱與日期存在 localStorage，重新整理不會消失 |
| F9 | 自訂行程 | 可自己輸入文字行程（例如「飯店 check-in」），指定第幾天、時間與預估花費（日圓，可不填） |
| F10 | 時間與備註 | 每個行程項目（景點或自訂）都能設定時間與備註；同一天內依時間自動排序，沒有時間的排在最後 |
| F11 | 旅程資訊 | 可輸入旅程名稱與出發日期；有出發日期時，每天會顯示對應的日期與星期 |
| F12 | 輸出 PDF | 一鍵產生列印版面，包含：旅程標題、每日行程表（時間／行程／備註／花費）、預算概估、行李清單（☑／☐）；在列印視窗選「另存為 PDF」 |

## 4. 畫面規劃
1. 頂部導覽列（錨點：景點、行程、預算、行李、日文）
2. Hero 區：標題＋簡介＋「開始規劃」「隨機推薦」＋即時統計
3. 景點探索區（篩選列＋卡片格）
4. 行程規劃區（天數、旅程名稱、出發日期、自訂行程表單、每天一欄；每個項目有時間、換天、備註）
5. 預算區（輸入欄位＋總計卡片）
6. 行李清單區（含「輸出 PDF」區塊）
7. 實用日文區
8. 頁尾
9. PDF 列印版面（平常隱藏，只在列印時顯示）

## 5. 技術限制
- 單一 `index.html`，CSS 與 JavaScript 皆寫在檔案內
- 不依賴任何外部套件或圖片（用 emoji 與漸層色），離線也能開啟
- PDF 以瀏覽器列印功能（`window.print()` ＋ `@media print`）產生，不需額外套件，中文不會亂碼
- 響應式設計，手機可操作
- 部署：GitHub Pages（Settings → Pages → Deploy from a branch → main / root）

## 6. 驗收標準
- 開啟網頁即可操作所有功能，無錯誤訊息
- 加入景點或自訂行程後，行程區與預算區即時更新
- 設定時間後，同一天的項目依時間由早到晚排列
- 重新整理後資料仍保留
- 按「輸出 PDF」後，預覽內容依序為：行程、預算、行李清單，且不含網頁導覽列與按鈕
